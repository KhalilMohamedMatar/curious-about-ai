Illustrative token numbers. Real dictionaries differ by model — that's fun fact #1.

In AI, text is swapped for numbers called tokens. Every chunk of text has a pre-assigned number in a fixed dictionary: arbitrary, but permanent. The word "like" might always be 143544, today and for the foreseeable future. So "I like you" might arrive at the model as 8833, 143544, 999. Write "I LIKE YOU" instead and the numbers change — to the model, these aren't the same words written louder; they're entirely different — broken into different chunks, each with its own pre-assigned number.

Fun Facts

The numbers aren't universal

Each AI model has its own dictionary: "like" gets one set of numbers in Claude, a completely different set in ChatGPT. Permanent within a model — meaningless across them.

Arabic tokens cost more

The dictionaries were built mostly on English — so Arabic words get chopped into more tokens.

Emojis cost more than words

Your 🙂 can cost you more than writing "thanks."
